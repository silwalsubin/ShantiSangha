# Simplicity

The app must feel like ONE calm experience, not a collection of modules.

## Why this matters

People come to ShantiSangha during emotionally heavy moments. If they have to think about where to tap, what tab to use, or how a feature works — we've already lost them. Complexity is the enemy of a wellness app.

## Rules

- **4 tabs maximum** — Home, Reflect, Journey, Friends. The first three are the solo practice loop (ground, reflect, see growth); Friends is the deliberate social surface gated by explicit consent. No further tabs.
- **One path, not seven doors** — guide users through a natural flow: ground yourself, reflect, see growth
- **If a feature needs explanation, it's too complex** — redesign it, don't add a tooltip
- **Every screen should flow into the next** — no dead ends
- **3 taps maximum** to start any activity
- **No redundant page titles** — the nav tells you where you are
- **No decorative clutter** — if it doesn't help the user, remove it
- **No bells and whistles** — resist the urge to add features that look impressive but add cognitive load

## How to apply

When adding a new feature, ask:
1. Can it live within an existing tab?
2. Does it make the flow simpler or more complex?
3. Would a first-time user understand it without instruction?

If the answer to #3 is no, simplify until it is.
